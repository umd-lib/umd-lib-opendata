# Dryad

UMD is a member of the <a href="https://datadryad.org/">Dryad Data
Community</a>, which is a community-owned resource that offers data curation
services in addition to large storage capacity for most kinds of datasets in
any discipline. A search is available with a limit to the <a
href="https://datadryad.org/search?f%5Bdryad_author_affiliation_name_sm%5D%5B%5D=University+of+Maryland%2C+College+Park">University
of Maryland, College Park Institution</a>.  You can find more information on
the <a
href="https://www.lib.umd.edu/research/oss/publishing-and-digital-projects/repository-services/open-data-repositories">UMD
Libraries website</a>.

## OpenAPI Specification

The Dryad API is built using the :any:`OpenAPI Specification <APIs OpenAPI
Specification>`, with both <a
href="https://datadryad.org/openapi.yml">YAML-based</a> and <a
href="https://datadryad.org/api/v2/docs/">HTML-based</a> documentation
available.

Endpoint: `https://datadryad.org/api/v2/`
